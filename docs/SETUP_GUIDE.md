# 🛠️ 북튜닝 개인버전 처음부터 끝까지 세팅 가이드

이 문서는 **북튜닝 개인버전(v4.4)** 을 내 노션(Notion)과 연결해 개인 서재 웹앱으로 세팅·운영하는 방법을 단계별로 안내합니다.

---

## 1단계. 배포용 노션 템플릿 복제하기

1. 아래 배포용 노션 템플릿 링크를 엽니다.
   👉 **[개인 독서 챌린지 (배포용) | Notion](https://app.notion.com/p/record-tuner/2a59a421189580169fa9d158783cee29)**
2. 오른쪽 상단의 **`복제(Duplicate)`** 버튼을 눌러 본인의 노션 워크스페이스로 가져옵니다.
3. 복제된 페이지 안에 아래 **4개의 데이터베이스**가 함께 복제되었는지 확인합니다.
   - `1주 1권 챌린지` (월별·기간별 챌린지 DB)
   - `1주 1권 읽기 책기록` (도서 DB)
   - `독서일지기록` (독서일지 DB)
   - `문장수집 DB` (인용구·메모 DB)

> 💡 **주의**: 데이터베이스의 **속성(컬럼) 이름**(`*챌린지 이름`, `*책 제목`, `*전체 페이지수`, `읽은 날짜` 등)은 웹앱 코드와 1:1로 연결되어 있으므로, 템플릿에서 복제한 그대로 유지해 주세요.

---

## 2단계. 노션 API 토큰(`NOTION_API_KEY`) 발급 & 권한 연결

### 2-1. 통합(Integration) 토큰 발급
1. [노션 내 API 통합 페이지](https://www.notion.so/profile/integrations)에 접속해 로그인합니다.
2. **`+ 새 API 통합(New integration)`** 버튼을 클릭합니다.
3. 아래 항목을 입력하고 저장합니다.
   - **이름**: `북튜닝 개인서재` (원하는 이름)
   - **연결된 워크스페이스**: 1단계에서 템플릿을 복제한 **내 워크스페이스** 선택
   - **유형**: `프라이빗(Internal)`
4. 생성 후 **`프라이빗 API 통합 시크릿`** 옆 `표시` → `복사`를 누릅니다. (`ntn_...` 또는 `secret_...` 형태)
   - 이 값이 **`NOTION_API_KEY`** 입니다.

### 2-2. 복제한 노션 페이지에 API 통합 연결하기 (필수!)
> ⚠️ **이 단계를 빠뜨리면 앱에서 `Could not find database with ID` 오류가 발생합니다.**

1. 1단계에서 내 워크스페이스로 복제한 **`개인 독서 챌린지`** 최상위 페이지를 엽니다.
2. 오른쪽 상단 **`⋯` (더보기)** 메뉴 클릭 → **`연결(Connections)`** 선택
3. 검색창에 방금 만든 **`북튜닝 개인서재`** 를 찾아 선택 → **`확인`** 클릭!
4. 상위 페이지에 연결하면 아래에 포함된 4개의 데이터베이스에도 권한이 함께 적용됩니다.

---

## 3단계. 4개 노션 데이터베이스 ID & 페이지 주소 찾기

복제한 페이지 안의 **4개 데이터베이스**를 각각 **전체 페이지로 열기** 한 뒤 주소창(또는 `⋯` → `링크 복사`)에서 **32자리 ID**를 꺼냅니다.

### 주소에서 ID 읽는 법
노션 데이터베이스 링크는 보통 다음과 같은 모양입니다.
```text
https://www.notion.so/myworkspace/1주-1권-챌린지-1234567890abcdef1234567890abcdef?v=99999999...
                                               └───────── 이 32자리가 DB ID ─────────┘
```
- 하이픈(`-`)이 없는 32자리 그대로 넣어도 되고, `8-4-4-4-12` 형식으로 넣어도 모두 동작합니다.
- `?v=` 뒤에 나오는 값은 뷰(View) ID이므로 **반드시 `?v=` 앞의 32자리**를 복사하세요.

| 환경변수 이름 | 연결할 노션 대상 |
|---|---|
| `NOTION_CHALLENGE_DB_ID` | `1주 1권 챌린지` 데이터베이스 ID |
| `NOTION_BOOK_DB_ID` | `1주 1권 읽기 책기록` 데이터베이스 ID |
| `NOTION_LOG_DB_ID` | `독서일지기록` 데이터베이스 ID |
| `NOTION_INSIGHT_DB_ID` | `문장수집 DB` 데이터베이스 ID |
| `NOTION_PAGE_URL` *(선택)* | 복제한 최상위 노션 페이지(`개인 독서 챌린지`) 전체 URL (푸터의 `노션 데이터베이스 열기` 버튼에 연결됨) |

## 4단계. AI & 도서 검색 API 키 발급하기

### 4-1. Google Gemini API 키 (`GEMINI_API_KEY` — 필수)
- 용도: AI 월간 독서 리포트 · 블로그 글 생성, 도서 감상문 초안, 문장수집 사진 OCR 문자 인식
- 발급 방법:
  1. [Google AI Studio](https://aistudio.google.com/apikey) 접속 및 로그인
  2. **`Create API key`** 클릭 → 발급된 `AIza...` 키 복사

### 4-2. 도서 검색 및 쪽수 연동 API 키 (표준 하이브리드 엔진)
> 📢 **도서 검색 엔진 최신 현황 (중요 공지)**
> - **알라딘 Open API**: **2026.10.30 서비스 공식 종료** (기존 TTBKey 사용 불가)
> - **네이버 도서 검색 API**: **2026.07.31 서비스 공식 종료** (도서 검색 지원 중단)
> - **북튜닝 표준 하이브리드 엔진**: 카카오의 풍부한 표지·서지정보와 국립중앙도서관의 공공 서지정보(총 쪽수 자동 연동)를 결합하여 운영됩니다.

1. **카카오 도서 검색 키 (`KAKAO_REST_API_KEY` — 표준 필수)**
   - 역할: 도서 제목/저자 검색, 고화질 표지 이미지 및 출판사·ISBN 서지 정보 제공
   - 발급: [Kakao Developers](https://developers.kakao.com/) 로그인 → `내 애플리케이션 추가` → 요약 정보의 **`REST API 키`** 복사

2. **국립중앙도서관 서지정보 키 (`NL_API_KEY` — 표준 필수)**
   - 역할: 카카오 도서 검색 결과의 ISBN 및 제목을 바탕으로 **정확한 전체 페이지 수(쪽수)를 자동 조회하여 매핑**
   - 발급: [국립중앙도서관 오픈API](https://www.nl.go.kr/NL/contents/N31101030700.do) 회원가입 → `인증키 신청` → 즉시 발급된 키 복사

> 💡 **카카오 + 국립중앙도서관 하이브리드 원리**: 카카오 API는 책 페이지(쪽수)를 제공하지 않고 국립중앙도서관 API는 표지 이미지를 제공하지 않습니다. 북튜닝은 카카오에서 표지와 도서 정보를 검색한 뒤, 13자리 ISBN을 통해 국립중앙도서관 서지정보에서 페이지 수를 자동으로 실시간 조회·결합하여 완벽한 도서 정보를 완성합니다.

3. *(참고/레거시)* **알라딘 (`ALADIN_API_KEY`) & 네이버 (`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`)**
   - 2026년 하반기 서비스 종료에 따라 현재 북튜닝에서는 비활성화 처리되어 있습니다. 카카오와 국립중앙도서관 키를 발급받아 사용하세요.

## 5단계. 배포 및 실행하기

### 방법 A. Vercel로 웹에 배포해 어디서나 쓰기 (PC · 모바일 추천)
1. [Vercel](https://vercel.com/)에 GitHub 계정으로 로그인 → **`Add New...` → `Project`** 선택
2. 이 Private GitHub 저장소를 **Import** 합니다.
3. **Environment Variables** 섹션을 열어 2~4단계에서 준비한 키들을 하나씩 등록합니다.
   - `NOTION_API_KEY`
   - `NOTION_CHALLENGE_DB_ID`
   - `NOTION_BOOK_DB_ID`
   - `NOTION_LOG_DB_ID`
   - `NOTION_INSIGHT_DB_ID`
   - `GEMINI_API_KEY`
   - `KAKAO_REST_API_KEY` *(도서 검색 및 표지 연동)*
   - `NL_API_KEY` *(국립중앙도서관 쪽수 자동 연동)*
   - `NOTION_PAGE_URL` *(선택)*
4. **`Deploy`** 버튼을 누르면 몇 분 뒤 나만의 북튜닝 웹앱 주소(`https://...vercel.app`)가 생성됩니다!

### 방법 B. 내 컴퓨터(로컬)에서 실행하기
> ⚠️ Google Drive 등 클라우드 동기화 폴더에서는 `npm install` 오류가 발생할 수 있으므로 `C:\dev\...` 같은 일반 로컬 폴더에서 실행하는 것을 권장합니다.

```bash
# 1. 저장소 클론
git clone <내-깃허브-저장소-주소>
cd 북튜닝-개인버전

# 2. 의존성 설치
npm install

# 3. 환경변수 파일 생성 (.env.example 복사 후 실제 키 입력)
cp .env.example .env.local

# 4. 개발 서버 실행
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하면 바로 사용할 수 있습니다.

## ❓ 자주 발생하는 문제 해결

- **Q. 화면에 책이나 챌린지가 뜨지 않고 노션 오류가 나요.**
  - 2-2단계에서 복제한 노션 페이지의 **`⋯` → `연결(Connections)`** 에 내 API 통합 앱이 연결되어 있는지 확인하세요.
  - 4개의 DB ID가 서로 바뀌어 들어가지 않았는지, `?v=` 뒤의 뷰 ID를 넣은 것은 아닌지 확인하세요.
- **Q. 푸터의 `노션 데이터베이스 열기`를 눌렀는데 안내 문구가 떠요.**
  - Vercel 또는 `.env.local`에 `NOTION_PAGE_URL`이 등록되지 않았기 때문입니다. 내 노션 페이지 URL을 추가한 뒤 재배포(또는 재시작)하면 바로 열립니다.
- **Q. API 키가 브라우저에 노출되지 않나요?**
  - 모든 환경변수는 `NEXT_PUBLIC_` 접두사 없이 Next.js 서버 Route Handlers에서만 사용되므로 개발자 도구나 클라이언트에 일체 노출되지 않습니다.
