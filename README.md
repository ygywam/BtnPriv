# 📚 북튜닝 (Book Tuning) 개인 독서 챌린지 v1.0

> **"1주 1권 독서 챌린지와 노션을 완벽하게 잇는 나만의 스마트 서재"**  
> 노션의 `1주 1권 챌린지` 데이터베이스와 실시간으로 동기화되어 날짜에 따라 도서, 독서일지, 문장수집이 해당 월 챌린지에 자동으로 매핑되고, Gemini AI가 월간 독서 리포트와 블로그 완성글을 집필해 노션 본문에 토글 블록으로 자동 보존해 줍니다.

---

## 🌟 핵심 특징

1. **로그인 없는 1인 전용 즉시 직행 서재**
   - 다중 사용자/닉네임/PIN 인증을 전면 배제하고, 접속하자마자 나의 책장과 현재 진행 중인 독서 챌린지로 직행합니다.

2. **날짜 기반 챌린지 자동 매핑 및 수식 100% 호환**
   - 도서 등록이나 독서일지 작성 시 읽은 날짜(YYYY.MM)를 기준으로 당월 챌린지 페이지에 자동 Relation 연결됩니다.
   - 새 달의 첫 기록 시 당월 1일(`*챌린지 시작일`)과 말일(`*희망 일수`)을 자동 계산하여 노션 챌린지 페이지를 생성하므로, 노션의 `*목표 종료일`과 `*진행상황` 잔디 수식이 빈틈없이 작동합니다.

3. **챌린지 기간 및 종류 세부 조절**
   - 기본 1달 외에도 **1주일(7일), 2주일(14일), 1달(당월 말일), 2달 연속(예: 9-10월, 61일)** 프리셋 및 수동 날짜 커스텀을 지원합니다.
   - 조절 시 노션의 시작일과 희망일수가 즉시 업데이트되어 노션 수식이 새로운 기간에 맞춰 자동 재계산됩니다.

4. **Gemini 2.5 AI 월간 독서 리포트 & 블로그 글 자동 저장**
   - 챌린지 기간 동안 작성한 도서 목록, 일자별 독서일지, 수집 문장들을 종합 분석하여 노션 8월 챌린지와 동일한 규격의 **[독서 리포트]**와 **[블로그 완성글 (후킹 제목 4개 포함)]**을 원클릭으로 생성합니다.
   - 생성된 결과물은 화면 확인 및 복사뿐만 아니라 노션 챌린지 페이지 본문 안에 **접이식 토글 블록으로 영구 저장**됩니다.

5. **도서 3대 검색 엔진 및 알라딘 쪽수 자동 추출**
   - 알라딘 TTB API (상세 LookUp 연동으로 쪽수 100% 자동 채움), 카카오 도서 검색, 네이버 도서 검색 지원.
   - 검색 후 상세 폼에서 정보(쪽수, 저자, 출판사, 별점)를 최종 확인 및 수정하여 등록.

6. **철저한 API 키 보안 (브라우저 노출 0%)**
   - 노션 키, Gemini 키, 도서 검색 API 키 등 모든 인증 정보는 Next.js 백엔드 서버(Route Handlers)에서만 호출됩니다.
   - 브라우저 개발자 도구의 Network 및 Sources 탭에 API 키가 절대 노출되지 않습니다.

## 🛠️ Vercel 환경변수 설정 가이드

Vercel 대시보드 (`Settings > Environment Variables`)에 아래 환경변수들을 등록합니다:

| 환경변수명 | 설명 | 비고 |
|---|---|---|
| `NOTION_API_KEY` | 노션 내부 통합 시크릿 토큰 (`ntn_...`) | 필수 (서버 전용) |
| `NOTION_CHALLENGE_DB_ID` | `1주 1권 챌린지` DB ID (`ea45d293...`) | 필수 |
| `NOTION_BOOK_DB_ID` | `1주 1권 읽기 책기록` DB ID (`80ec125c...`) | 필수 |
| `NOTION_LOG_DB_ID` | `독서일지기록` DB ID (`b3064ad0...`) | 필수 |
| `NOTION_INSIGHT_DB_ID` | `3️⃣ 문장수집 DB` ID (`ceb9a421...`) | 필수 |
| `GEMINI_API_KEY` | Google Gemini API 키 (리포트 & OCR) | 필수 |
| `ALADIN_API_KEY` | 알라딘 TTB 키 (쪽수 자동 추출) | 권장 |
| `KAKAO_REST_API_KEY` | 카카오 REST API 키 | 권장 |
| `NAVER_CLIENT_ID` | 네이버 검색 클라이언트 ID | 선택 |
| `NAVER_CLIENT_SECRET` | 네이버 검색 클라이언트 시크릿 | 선택 |
| `NL_API_KEY` | 국립중앙도서관 ISBN 연동 키 | 선택 |

## 💻 로컬 개발 환경 실행

```bash
# 1. 의존성 설치
npm install

# 2. .env.local 환경변수 설정 (.env.example 참조)

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 브라우저에서 http://localhost:3000 접속
```
