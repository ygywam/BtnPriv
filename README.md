# 📚 북튜닝 (Book Tuning) 개인 독서 챌린지 v4.4

> **"1주 1권 독서 챌린지와 노션을 완벽하게 잇는 나만의 스마트 서재"**  
> 노션의 `1주 1권 챌린지` 데이터베이스와 실시간으로 동기화되어 날짜에 따라 도서·독서일지·문장수집이 해당 월 챌린지에 자동으로 연결되고, 모바일과 PC 모두에 최적화된 5대 탭 대시보드로 독서 흐름을 한눈에 관리할 수 있습니다.

---

## 🌟 핵심 특징 (v4.4)

1. **로그인 없는 1인 전용 즉시 직행 서재**
   - 다중 사용자/닉네임/PIN 인증을 배제하고, 접속 즉시 나의 독서 대시보드로 직행합니다.

2. **모바일 · PC 반응형 5대 탭 구조 (`홈` · `서재` · `챌린지` · `피드` · `도감`)**
   - **🏠 홈**: 상단 도서 검색바(`책 제목/저자 검색하기`) + **지금 읽는 책**(미완독 도서 & 세그먼트 진행률 바) + **챌린지 기간 기반 월별 캘린더 & 등록 권수 목표 원형 게이지** + **최근 독서기록** 피드
   - **📚 서재 (macOS Dock 휠 캐러셀)**: 책장 선반 위에서 마우스 휠·드래그·화살표로 책을 가로로 넘기고, 마우스를 올리면 해당 책과 인접한 책이 물결처럼 확대되는 Dock 스타일 서재
   - **🏆 챌린지**: 월별·기간별 챌린지를 카드 형식으로 나열해 달성률, 참여 도서 표지, 노션 잔디 현황, 미완독 도서 일괄 이월, 기간 조절 및 AI 리포트를 한곳에서 관리
   - **💬 피드**: 모든 독서일지와 문장수집 기록을 시간순(최신순) 타임라인으로 모아보고 유형·키워드 필터링 지원
   - **🐾 도감**: 완독(100%)한 책의 표지를 컬렉션 그리드로 진열하고 총 완독 권수·누적 페이지를 집계

3. **날짜 기반 챌린지 자동 매핑 & 기간 세부 조절**
   - 도서 등록이나 독서일지·문장수집 작성 시 읽은 날짜를 기준으로 당월 챌린지 페이지에 자동 Relation 연결되며, 챌린지 기간(1주·2주·1달·2달·직접 입력)도 자유롭게 조절할 수 있습니다.
   - 챌린지 기간 캘린더는 해당 챌린지 기간의 독서일지·문장수집 날짜를 집계(`N일 읽음 · N페이지 · N권 완독`)해 표시하고, 날짜 클릭 시 당일 기록을 바로 확인할 수 있습니다.

4. **Gemini 2.5 AI 월간 독서 리포트 · 블로그 글 & OCR**
   - 챌린지 기간 동안 모은 일지와 문장을 종합 분석해 **[독서 리포트]**와 **[블로그 완성글]**을 생성하고 노션 챌린지 페이지 본문에 접이식 토글 블록으로 영구 저장합니다.
   - 문장수집 시 책 본문/손글씨 사진을 업로드하면 Gemini OCR로 텍스트를 추출하고 노션 페이지 본문에 이미지 블록을 함께 첨부합니다.

5. **도서 3대 검색 엔진 & 표지/페이지 커버 동시 연동**
   - 알라딘 TTB API(쪽수 자동 추출), 카카오 도서, 네이버 도서 검색을 지원하며, 도서 등록·수정 시 노션 `표지` 속성과 페이지 상단 `cover`를 동시에 저장합니다.

6. **포스트잇 휠 캐러셀 개발로그 & 가이드 영상 탑재**
   - 상단 `📝 개발로그`에서 `v1.0`부터 `v4.4`까지의 전체 버전을 마우스 휠로 넘겨볼 수 있으며, `📖 사용법` 모달에서 소개·가이드 영상을 바로 시청할 수 있습니다.

7. **철저한 API 키 보안 (브라우저 노출 0%)**
   - 노션, Gemini, 도서 검색 등 모든 API 키는 Next.js 서버 Route Handlers에서만 사용되며 클라이언트 번들에 노출되지 않습니다.

## 🔗 내 노션 페이지 연결

본 웹앱은 개인 노션 주소를 코드에 하드코딩하지 않고 환경변수(`NOTION_PAGE_URL`)로 연결합니다.  
환경변수가 설정된 경우에만 푸터의 `📚 노션 데이터베이스 열기 ↗`가 해당 주소로 연결되며, 미설정 시 개인 주소가 외부에 노출되지 않습니다.

## 🛠️ Vercel 환경변수 설정 가이드

Vercel 대시보드(`Settings > Environment Variables`)에 아래 환경변수들을 등록합니다.

| 환경변수명 | 설명 | 비고 |
|---|---|---|
| `NOTION_API_KEY` | 노션 내부 통합 시크릿 토큰 (`ntn_...`) | 필수 (서버 전용) |
| `NOTION_CHALLENGE_DB_ID` | `1주 1권 챌린지` DB ID (`ea45d293...`) | 필수 |
| `NOTION_BOOK_DB_ID` | `1주 1권 읽기 책기록` DB ID (`80ec125c...`) | 필수 |
| `NOTION_LOG_DB_ID` | `독서일지기록` DB ID (`b3064ad0...`) | 필수 |
| `NOTION_INSIGHT_DB_ID` | `3️⃣ 문장수집 DB` ID (`ceb9a421...`) | 필수 |
| `GEMINI_API_KEY` | Google Gemini API 키 (리포트 & OCR) | 필수 |
| `ALADIN_API_KEY` | 알라딘 TTB 키 (쪽수 자동 추출) | 권장 |
| `KAKAO_REST_API_KEY` | 카카오 REST API 키 | 권장 |
| `NAVER_CLIENT_ID` | 네이버 검색 클라이언트 ID | 선택 |
| `NAVER_CLIENT_SECRET` | 네이버 검색 클라이언트 시크릿 | 선택 |
| `NL_API_KEY` | 국립중앙도서관 ISBN 연동 키 | 선택 |
| `NOTION_PAGE_URL` | 푸터 '노션 데이터베이스 열기' 바로가기 URL | 선택 (미설정 시 비공개 유지) |

## 💻 로컬 개발 환경 실행

```bash
# 1. 의존성 설치 (Google Drive 가상 드라이브가 아닌 로컬 NTFS 경로 권장)
npm install

# 2. .env.local 환경변수 설정 (.env.example 참조)

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 브라우저에서 http://localhost:3000 접속
```
